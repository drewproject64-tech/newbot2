# Ads-Oriented Compliance Checklist

The project intentionally has one clear purpose: personal task/to-do management.

- Exactly 3 primary main-menu buttons.
- Each primary button has a real task-management purpose.
- /start shows the welcome message and main menu.
- /menu restores the main menu.
- Invalid input receives a useful response.
- Tasks are persisted per Telegram user in SQLite.
- Users can add tasks.
- Users can view active tasks.
- Users can mark active tasks complete.
- Users can view completed tasks.
- Users can delete task records using task numbers.
- No external URLs are used in the bot interface or copy.
- No gambling, casino, betting, prize, or real-money gaming functionality.
- No redirect-only functionality.
- Bot profile text matches the task-management functionality.
- Token comes from BOT_TOKEN.

Telegram Ads approval cannot be guaranteed; final decisions are made by Telegram.
